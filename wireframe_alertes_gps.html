Notes de conception — wireframe connecté

  • La colonne Gravité et la Justification ne sont plus codées en dur : elles sont calculées en direct par la même logique que routage_alertes_gps.py (récurrence du même type d'alerte sur 24h pour le même véhicule, horaire de nuit pour les arrêts suspects).
  • Le tri par gravité (Critique → Élevée → Modérée → Faible) reproduit exactement l'ordre de sortie du script Python.
  • L'équipe reste déterminée par type_alerte (Excès de vitesse → QHSE, Déviation → RO, Arrêt suspect → SO), comme dans la v1 du wireframe.
  • Dans une implémentation réelle, ce JavaScript serait remplacé par un appel API vers le même moteur que le PoC Python — la logique métier ne change pas, seul le langage d'exécution diffère.
